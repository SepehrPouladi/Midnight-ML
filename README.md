# 🌙 Midnight ML

### A Nightly Journey into Machine Learning

Midnight ML is a personal learning project dedicated to understanding, implementing, and applying Machine Learning algorithms.

The project follows two main phases:

## Phase I — From Scratch

Understanding the mathematical foundations of Machine Learning algorithms and implementing them using Python, without relying on pre-built Machine Learning libraries.

- Mathematical derivations
- Synthetic datasets
- Manual algorithm implementation
- Step-by-step experiments
- Performance and error analysis

## Phase II — Industrial Applications

Applying the acquired knowledge to real-world industrial datasets and engineering problems.

- Industrial data analysis
- Data preprocessing
- Model development
- Performance evaluation
- Practical engineering applications

## Philosophy

**Understand the mathematics. Build the algorithm. Apply it to the real world.**

One night. One experiment. One step forward.
